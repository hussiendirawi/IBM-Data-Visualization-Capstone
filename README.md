# IBM Data Visualization Capstone Project

This repository contains the final capstone project for the IBM Data Visualization course, focusing on analyzing historical automobile sales and economic recessions using Python.

## 📊 Project Overview
- **Objective:** Analyze how macroeconomic recessions impact automobile sales, advertising expenditure, and vehicle types over time.
- **Tools & Libraries:** Python, Pandas, Matplotlib, Seaborn.

## 📈 Visualizations & Insights
The project generates several key visualizations stored in this repository:
1. **Automobile Sales Trend During Recessions** (`1.png`)
2. **Year-by-Year Variation in Vehicle Sales** (`2.png`)
3. **Total Vehicle Sales by Vehicle Type During Recessions** (`3.png`)
4. **Advertising Expenditure vs. Sales** (`4.png`)
5. **GDP and Unemployment Impact Analysis** (`5.png`)
